# Anfas Digital Works — Business Landing Page

Responsive landing page for a small software and web development service. The page presents Mohammed Anfas’s services in a realistic business context.

## Sections

- Navigation with primary call to action
- Hero value proposition
- Four service cards
- About section
- Three-step process
- Contact form
- Footer

## Tech used

Semantic HTML5 and responsive CSS3 using Grid, Flexbox, media queries, and native HTML form validation.

## Run locally

Open `index.html` in a browser or use VS Code Live Server.
